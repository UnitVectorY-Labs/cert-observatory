🔐 Cert Observatory

Retrieve and inspect TLS certificate chains for any domain. The retrieval is done server-side, so results may differ from your local view if a different certificate is served or there is a man-in-the-middle.

Retrieve Certificate Chain

What this tool does

  • Server-side retrieval of the TLS certificate chain presented by the server
  • Full chain displayed with each certificate decoded for inspection
  • Inspection only – chain trust is not validated
  • TLS handshake on port 443; no HTTP requests, no redirects
